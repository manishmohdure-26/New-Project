# Generate User Stories — Checklist

## Agent: Narrator (User Stories Agent)

### Context & Document Collection
- [ ] project-docs/ scanned for available documents
- [ ] User confirmed document selection
- [ ] Scope determined (Full / Feature-specific / Incremental)

### Document Analysis
- [ ] All selected documents analyzed
- [ ] User roles/personas identified
- [ ] Business rules and constraints documented

### Epic Definition
- [ ] Epics defined using EPIC-MODULE format

### User Stories
- [ ] User stories follow "As a... I want... So that..." format
- [ ] Acceptance criteria use Given/When/Then format
- [ ] Stories are independent and testable
- [ ] Priorities assigned using MoSCoW framework
- [ ] Source document references included per story
- [ ] Story IDs follow EPIC-ID-US-NNN format

### Gaps & Traceability
- [ ] Gaps and assumptions documented
- [ ] Dependency map created
- [ ] Coverage matrix links stories to source documents

### Output
- [ ] Output saved to outputs/user-stories-agent/
